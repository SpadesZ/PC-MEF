{{ curves_svg | safe }}

怎麼看這張圖：兩軸都自 0 起，所以曲線離開基線那一點就是 最早回波到達的時間；圓點標的是峰值，虛線落在時間軸上的位置就是峰值時間。
要檢查什麼：峰值應該遠離時間窗右緣。貼在右緣代表回波被 截斷，那次模擬的總能量會偏低而且不可用 —— 這是這張圖唯一的科學檢查。 時間軸由場景幾何推導，不沿用 cornell_box 預設（NOTE-013）。
